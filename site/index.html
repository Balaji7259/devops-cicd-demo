Selected work

Automated CI/CD deployment pipeline

Designed, built and operated solo

A push to main builds a Docker image, smoke-tests it against the routes the site actually serves, publishes it to Amazon ECR under an immutable commit-SHA tag, then replaces the container on EC2 through AWS Systems Manager. There is no SSH key, no inbound SSH rule, and no credential stored on the server. If the new container never answers /healthz, the previous image is restored automatically and the pipeline still fails — a recovery is not a pass.
